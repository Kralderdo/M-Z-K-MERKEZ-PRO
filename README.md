🎵 MÜZİK MERKEZİ PRO

Modern tasarımlı, mobil uyumlu müzik arama ve dinleme uygulaması.

Özellikler

- Şarkı ve sanatçı arama
- Apple iTunes üzerinden müzik önizlemeleri
- İzinli doğrudan ses bağlantılarını oynatma
- Favori şarkılar ve çalma kuyruğu
- Ses ve oynatma kontrolleri
- Desteklenen cihazlarda arka plan medya kontrolleri
- Ana ekrana eklenebilen PWA tasarımı
- Koyu tema ve mobil uyumlu arayüz

Teknolojiler

- Next.js
- React
- TypeScript
- CSS
- Apple iTunes Search API

Yerel çalıştırma

npm install
npm run dev

Ardından tarayıcıda "http://localhost:3000" adresini aç.

Yayınlama

Projeyi GitHub deposuna gönder ve Vercel üzerinden içe aktararak dağıtım yap.

Önemli not

iTunes arama sonuçları genellikle kısa önizlemeler sunar. Tam şarkı erişimi garanti edilmez. Doğrudan ses bağlantılarında yalnızca erişim iznin bulunan içerikleri kullan.

Seslerin arka planda çalınması tarayıcıya ve cihaza bağlıdır.
